#

This is not just a blog — it's a space for building and sharing web applications, tools, games, AI demos, and creative experiments. The project uses Next.js 16 with React 19, TypeScript, Tailwind CSS, and CSS Modules.

## What to expect

- **Blog posts** about web development and experiments
- **Lab apps** — interactive tools and demos built in the browser
- **Public API integrations** — exploring data from free APIs
- **Clean architecture** — feature-based, minimal dependencies

## Tech Stack

- **Next.js 16** — App Router, Server Components, Turbopack
- **React 19** — Latest React features
- **TypeScript** — Type safety throughout
- **Tailwind CSS + CSS Modules** — Two style systems, no UI framework
- **Vercel** — Deployment

The philosophy: keep it simple, use browser-native capabilities first, and add complexity only when genuinely needed.

Stay tuned for more experiments and apps coming to the Lab!
