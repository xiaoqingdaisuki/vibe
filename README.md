# Vibe

This is a personal Web Lab project designed to host web applications, experiments, demos, and writing born from spontaneous inspiration.

## Overview

### Blog

The blog is a lightweight space for thoughts, notes, and experiments, powered by local Markdown and MDX content.

### Skills

`/lab/skills` is a lightweight reference app for collecting AI coding agent skills, tools, and related resources.

## Tech Stack

- Next.js 16 with App Router
- React 19
- TypeScript with strict mode
- Tailwind CSS v4
- CSS Modules
- MDX content via `next-mdx-remote`
- Vercel-ready deployment model
